# Bundle & Combo Offers

`/bundles` and `/bundles/design-preview` implement the approved reference with native HTML and clipped decorative artwork. The desktop routine photo/details split becomes stacked on mobile; the final odd combo card uses the supplied mobile horizontal layout. Shared Deals styles provide consistent header/footer and accessible controls; all bundle-specific styles are scoped.

Working interactions: category filters, search across included items, price/savings sorting, device-local saved previews, mobile navigation, expandable routine details and accessible native bundle dialogs. Savings derive from the displayed original/offer prices. Enquiries open the existing assistant with the bundle name; no message is sent automatically.

All products/prices are explicitly sample content, noindex and not purchasable. This does not create inventory records, admin bundle CRUD, real discount rules or checkout integration. Before real sales, confirm actual products/sizes and pricing, enforce availability per included SKU and recalculate discount/stock on the server. Hero/photo packaging is illustrative and is not a certification or sourcing claim.
