# Customer care reference implementation

Five responsive UI previews: /shipping/design-preview, /returns/design-preview, /privacy/design-preview, /terms/design-preview and /faq/design-preview. Shared native header, active navigation, text-only footer, accessible details accordions, FAQ search/category filtering and print styles for terms. Reference artwork supplies only decorative banner regions; text and controls remain HTML. Footer links from homepage, shop and information pages now reach these pages.

These are noindex design previews. Shipping fees and delivery times remain unconfirmed. Privacy and terms copy is draft material; the merchant must confirm actual data practices, returns eligibility, charges and timings before publishing enforceable policies. No payment, order tracking or database integration is implied.
